# Impact-Analysis-GoodThought-NGO-Initiatives
Datacamp/Datalab PostgreSQL Project
Project goal: how data-driven insights can direct and enhance GoodThought's humanitarian efforts. 
Project encapsulates detailed records of assignments, funding, impacts, and donor activities from 2010 - 2023.
ERD diagram provided to show visual representation of the relationships between these data tables.

Project questions: 
-- highest donation assignments
-- top regional impact assignments
